# Tech Nexus

Project Name: STIC - Students' Technical and Innovation Club

Overview

Build a modern, responsive, premium-looking website for a university Computer Science Club. The design should feel similar to websites from Google Developer Groups, IEEE, ACM, and top university tech communities.

The website should be clean, minimal, futuristic, and professional with subtle animations, glassmorphism effects, smooth scrolling, gradients, and dark mode by default.

Use React + TypeScript + Tailwind CSS with beautiful reusable components.
